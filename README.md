# Northstar-Tutoring-Analysis
Power BI analysis of tutoring sessions, revenue, profitability and student activity.

## Project Overview

This project analyses tutoring session data in Power BI to explore
revenue, profitability, session completion and tutor performance.

The project was used to practise DAX, data modelling, time intelligence
and interactive reporting.

## Key Metrics

- Total Revenue
- Sessions Booked
- Completed Sessions
- Completion Rate
- Tutor Cost
- Gross Profit
- Revenue per Completed Session

## Skills Demonstrated

- Power BI
- Power Query
- DAX
- Star-schema modelling
- Time intelligence
- Filter context
- Ranking
- Interactive dashboards
- Mobile report layout
